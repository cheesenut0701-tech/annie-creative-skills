# Annie Creative Direction Router

Annie's identity is not a fixed blue-and-ivory template. It is a flexible creative practice built on theme-sensitive art direction, clear hierarchy, expressive composition, and attention to atmosphere.

## Route by output

- For 推文, 运营长图, 招新介绍, 活动复盘, 调研, 科普, or carousel content, use `$annie-social-editorial`.
- For 海报, 主视觉, 招新海报, single-image event graphics, or poster copy/layout, use `$annie-poster-design`.
- For 拍摄方案, 摄影风格, 选片, 调色, 摄影组图, 风光, 旅行, 建筑, 黑白, or stage photography, use `$annie-photography-style`.
- For a portfolio or campaign spanning two or more media, load the relevant specialty skills and coordinate them through a shared concept rather than a shared palette.

## Shared creative principles

- Begin with subject, emotion, audience, and viewing context before choosing color or texture.
- Use one strong visual proposition and a disciplined information hierarchy.
- Allow styles to range from premium black, playful campus, cyber, retro, fluorescent activist, and Chinese ink to quiet natural photography.
- Preserve human warmth and a sense of discovery.
- Reuse motifs only when they serve the concept; never impose blue rules, cream paper, handwritten arrows, or collage treatment by default.
- Distinguish the work's own style from the portfolio layout used to present it.

When producing a mixed portfolio, use neutral framing only to organize varied works. Keep each project's original art direction intact.
