# Annie Social Editorial

Turn dense information into a scrollable visual story. Annie's signature here is not one palette: it is the ability to choose a distinctive theme, build modular sections, and keep long content lively through alternating density, scale, and media.

## Working method

1. Identify the topic's emotional register and choose one art direction from [references/art-directions.md](references/art-directions.md).
2. Build a narrative spine: hook, context, key points, people/evidence, action or closing.
3. Use recurring modules and navigation cues so a long graphic feels like one system.
4. Vary rhythm: dense copy block, visual pause, image cluster, numbered point, then action block.
5. Keep the artwork theme-specific. Do not apply the portfolio's blue header or ivory background unless the topic genuinely calls for it.

Read [references/longform-patterns.md](references/longform-patterns.md) for structure and [references/copy-voice.md](references/copy-voice.md) for writing.

## Non-negotiables

- The first screen must state the topic quickly and create curiosity.
- Use one dominant visual grammar per piece; contrast can occur between sections, not as random style switching.
- Make mobile body text readable and keep QR/action details isolated near the end.
- Use real screenshots, portraits, data, or process material as evidence when available.
- Decorative English may add rhythm but never replace necessary Chinese information.
- Check hierarchy at thumbnail size and readability at phone width.
