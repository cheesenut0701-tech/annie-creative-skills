# Long-form patterns

## Recommended sequence

1. Cover hook: topic, emotional promise, and one strong motif.
2. Orientation: who/what/why in a compact card.
3. Main story: 3-6 numbered or titled modules.
4. Evidence: photos, portraits, screenshots, charts, or quotations.
5. Participation: time, place, method, or next action.
6. Closing: emotional line plus QR/contact area when needed.

## Rhythm rules

- Repeat a header, number, tab, or line motif every 1-2 screens.
- Alternate full-width statements with narrower cards.
- Use large numerals for key findings and small labels for metadata.
- Break long copy into chunks of roughly 2-5 lines; longer passages need a strong reason.
- When presenting many people, use one portrait system and consistent name/role placement.
- Treat QR codes as utility blocks with breathing room, never decorative texture.

## Evidence patterns

- Recruitment: role card + task + real scene + application action.
- Interview: portrait + quote + daily detail + takeaway.
- Research: question + numbered finding + chart/photo + implication.
- Event recap: opening atmosphere + timeline + people + highlight + closing emotion.
- Recommendation: item badge + short review + category + numbered list.
